# Repository instructions

## Reviewing comments and user feedback

- Always include GitHub Discussions, including nested replies, alongside issue comments, PR comments and PR reviews when reviewing repository updates or user feedback.
- Check each source for the requested period. Paginate as needed; do not treat a small list of recent comments as a complete review. State the scope and any sources that could not be checked.
- Distinguish user reports and confirmations from maintainer updates and bot comments. Link directly to the feedback and include its date.
- When a referenced number is absent from issues and PRs, check Discussions before reporting it as missing.
