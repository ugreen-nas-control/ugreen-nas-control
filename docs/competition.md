## Approaches

Kernel-module LED and fan plugins (ich777 ugreenleds-driver and its forks, miskcoo's `led-ugreen.ko`) need a build per Unraid kernel. They broke on Unraid 7.3.3 and 7.3.4 (kernel 6.18.54 and 6.18.58), 7.4.0 and 7.4.1 each needed a rebuilt module (kernel 6.18.60 and 6.18.64, [ich777 it87-driver](https://github.com/ich777/unraid-it87-driver/releases)), and on 7.4.0-beta.2 a prebuilt `led-ugreen.ko` without `CONFIG_LEDS_BRIGHTNESS_HW_CHANGED` hangs the boot ([miskcoo#129](https://github.com/miskcoo/ugreen_leds_controller/issues/129), [#130](https://github.com/miskcoo/ugreen_leds_controller/issues/130), [#131](https://github.com/miskcoo/ugreen_leds_controller/issues/131)). This plugin uses no kernel module.
