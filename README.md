## What it does

UGREEN builds its boxes with their own fan controllers, LED chips and watchdog. Unraid does not know them. The plugin does, and adds a settings page, a dashboard tile and a command line.

- **Case view.** Your box as it is: bays with drive temperatures and LED colours, rear ports, M.2, RAM, PCIe. [Live demo](https://ugreen-nas-control.github.io/ugreen-nas-control/demo/?model=dxp6800-pro).
- **Fan curves in rpm.** Presets or your own curve, measured rpm, full speed when too hot, BIOS values back if the plugin stops. [More on fans →](docs/fan.md)
- **LEDs that say something.** Colour, effects and brightness per LED: disk activity, errors, SMART, network speed, night mode. [More on LEDs →](docs/led.md)
- **Hardware watchdog, kept on.** Leave it armed in the BIOS, the plugin feeds it, a frozen box reboots itself. [More on the watchdog →](docs/watchdog.md)
- **Sensors, dashboard tile, MQTT.** Sleeping disks stay asleep; status to Home Assistant, read-only. [More on MQTT →](docs/mqtt.md)
- **7 languages**, a command line (`ugreen-nas-ctl`, `ugreen-nas-fan`). [More on the CLI →](docs/cli.md) · [Languages →](docs/translations.md) · [FAQ →](docs/faq.md)

## Install

1. Unraid: **Plugins, Install Plugin**
2. Paste this URL, hit **Install**:

```
https://raw.githubusercontent.com/ugreen-nas-control/ugreen-nas-control/main/plugin/ugreen-nas-control.plg
```

3. Open **Settings, UGREEN NAS Control**. It names the model it found.

Update: **Plugins, Check for Updates**. Next build (latest head of `next`, not for production): install `https://ugreen-nas-control.github.io/ugreen-nas-control/next/ugreen-nas-control.plg`; it keeps your settings. [Channels and going back →](docs/releasing.md) · [Unraid versions →](docs/unraid.md)
